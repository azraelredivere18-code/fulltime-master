# 全职高手 0.14.0

独立编写的 Windows 求职投递客户端。原版“一键职达”只用于静态功能分析；本程序不加载原 EXE，也不连接原版授权服务。

## 安装与使用

1. 解压完整 Windows 压缩包，运行 `全职高手.exe`。需要 Microsoft Edge WebView2 Runtime。
2. 在“任务与设置”中新建任务，填写岗位关键词、城市、**全职或实习**，并选择招聘渠道“不限／仅校招／仅社招”和适用平台。校招、社招筛选需要页面明确标识；不能判明渠道的岗位不会在对应任务中自动投递。可开启销售岗位屏蔽、公司黑名单与异地过滤。
3. 主界面选择平台，打开其内置浏览器，**自行登录并完成人机验证**。在招聘网站准备好简历后点击“开始自动投递”。要同时运行第二个平台，切换平台选择框，再打开第二个浏览器窗口、手动登录并点击“开始自动投递”。最多同时运行两个平台；切回某个平台可以单独停止它。网站登录、验证码和简历选择仍按各站实际页面处理。
4. 在“查看记录”核对结果。只有页面显示明确成功回执才记为“已确认”；点击后未取得回执的记录标为“待核实”，不会盲目重复投递。页面诊断会导出不含账号、Cookie、简历正文的控件结构，供网站改版后校准。

## 企业官网投递助手

主界面点击“企业官网投递”，输入完整 HTTPS 招聘网址，在单独的内置浏览器窗口手动登录。可在助手中填写姓名、联系方式、教育等常用资料并加密保存到当前 Windows 账户；身份证号默认不填入网站，需要本次单独勾选。先点击“识别可填写字段”，核对浏览器当前域名，再点击“填写空白字段”。程序只处理当前页面标签明确、唯一且可见的空白文本或下拉字段，不操作密码、验证码、附件、内嵌网页或提交按钮。网站跳转到新的招聘系统域名时，需人工核对网址并确认新域名。逐项检查网页内容并自行提交；看到成功提示后可填写公司和岗位，保存“手动确认”记录。

资料表上方可以“读取已选简历”（任务设置中选过的 PDF／DOCX），或另选本地简历。程序只在本机提取字段，显示候选值供核对；用户勾选后才填入资料表，仍需点击“加密保存资料”。已有资料默认不覆盖，身份证号默认不勾选；多处冲突值、扫描版 PDF 和含糊字段留给用户手动确认。导入不会更改招聘平台的上传简历设置。

识别阶段只向网页传送已保存资料的字段名，不传送资料内容；填写前会再次核对当前网址和表单结构。网页或资料变化后需重新识别。紧急联系人、家属、推荐人、银行账户等字段不会自动填写。职位网址记录保留安全的岗位编号或岗位路由，不保存会话参数。官网表单差异很大，重复的教育／工作经历模块、日期控件、级联地区、跨域内嵌表单及补充问答仍需手工填写。保存的资料位于 `%LOCALAPPDATA%\OneClickJobRebuild\official_profile.dpapi`，由 Windows DPAPI 保护；更换 Windows 账户后无法直接解密。

## 网站状态

| 平台 | 当前功能与验收状态 |
| --- | --- |
| BOSS直聘 | 搜索、筛选、自动发起沟通；用户已反馈自动投递可用。 |
| 智联招聘 | 有搜索、简历确认和回执适配器；登录后的完整实投未验收。 |
| 前程无忧、应届生 | 目前在选择简历或跨站申请时停下等待人工操作，不能称为全自动。 |
| 猎聘、拉勾 | 投递入口或安全验证可部分识别；登录后的投递流程未验收。 |
| 牛客网 | 社招／实习与校招入口分开；官网闪投职位需要转企业官网助手，校招列表和站内申请仍需校准。 |
| 国聘网 | 新增实验适配：职位搜索与候选申请入口；登录后简历选择和成功回执仍需逐站核验，回执不明只记“待核实”。 |

BOSS 本工具每日最多预占 120 个名额，并按所选地区尽量均分、顺延；其他网站各设 30 个本地试运行名额。这些是本工具的限制，并非平台官方规则。名额按北京时间计，点击后回执不明仍占额。任务、记录及独立浏览器会话继续保存在 `%LOCALAPPDATA%\OneClickJobRebuild`，升级不会清空旧数据。

双平台运行时，每个平台有自己的浏览器窗口、任务状态和本地日名额。选择“过滤10天内不同平台投递过的公司”时，程序在预留投递名额的同一数据库事务里复核公司，避免两个任务同时对同一公司发起投递。没有读到公司名的职位无法使用这项公司去重。两个浏览器窗口共享本机 WebView2 用户数据目录；不同网站按各自域名保存登录状态。智联等平台的登录后完整投递流程仍需逐站实测，两个窗口可并行不等于这些网站已通过实投验收。

当前未接入 AI 匹配：任务的 AI 提示词须留空，匹配度设为 `0`。简历附件上传仅在网页唯一文件输入框且可见成功提示时确认；否则请在网站手动上传。登录、安全验证及复杂补充问答须人工完成。

网站原生筛选设置只在 BOSS 的招聘者类型与活跃状态上完成迁移。其他站点旧配置会在启动前明确提示清除；任务的关键词、城市、正则、岗位类型、销售排除仍由本程序执行。全职任务会拒绝非 BOSS 站点无法判明岗位类型的卡片；BOSS 默认职位搜索保留原有投递行为，同时对可见的实习标记进行拦截。

源码包可在项目目录运行 `python app.py`，或使用 `python build.py` 重新构建。分析边界见 `REBUILD_REPORT.md`，本次平台校准见 `PLATFORM_AUDIT_0.14.0.md`，双平台状态见 `PARALLEL_AUDIT_0.13.0.md`。
